NEW FEATURE: AI AUTO VIDEO EDITING STUDIO

Create three editing modes:

1. AUTO DOCUMENTARY EDITING
2. AUTO REELS / SHORTS EDITING
3. AUTO CINEMATIC EDITING

AUTOMATIC VIDEO ANALYSIS:
When a user uploads a video, the AI must:

- Watch and analyze the complete video.
- Listen to and understand the original voice.
- Generate a transcript with timestamps.
- Identify scenes, important moments, pauses, mistakes and unnecessary footage.
- Understand the topic and context before editing.

AUTOMATIC EDITING:
The AI should automatically:

- Remove unnecessary pauses and mistakes.
- Cut and arrange scenes according to the story.
- Identify where background replacement is required.
- Select relevant B-roll footage.
- Add suitable background music.
- Add sound effects at appropriate moments.
- Improve voice clarity and audio levels.
- Generate synchronized Hindi and English subtitles.
- Add cinematic transitions and visual effects.
- Apply color correction and grading.
- Add titles, animations and documentary-style graphics.
- Maintain synchronization between video, voice and music.

SMART B-ROLL:
AI must understand the spoken sentences and select relevant B-roll visuals according to their meaning and timestamps.

BACKGROUND:
Detect the subject and background. Replace the background only when appropriate. Preserve the original subject.

USER CONTROL:
After automatic editing, show:

- Original video preview.
- Edited video preview.
- Editing timeline.
- B-roll selection.
- Music and sound settings.
- Subtitle editing.
- Background controls.
- Undo and redo.
- Manual editing options.

FINAL EXPORT:
Allow users to export the finished video in:

- 9:16 vertical format.
- 16:9 landscape format.
- 1:1 square format.
- 720p and 1080p where supported.

FREE TECHNOLOGY:
Prefer open-source and free tools:

- FFmpeg for video processing.
- Whisper for speech recognition.
- OpenCV for video analysis.
- Remotion for video composition.
- Open-source AI models where practical.

TECHNICAL REQUIREMENTS:

- Build real working functionality, not demo buttons.
- Create a modular video editing pipeline.
- Use a secure backend for AI processing.
- Never expose API keys in frontend code.
- Do not use paid APIs by default.
- Clearly show when a feature needs an external service.
- Use local/browser processing where practical.
- Handle large files and processing errors.
- Show editing progress to the user.
- Allow final video download.

IMPORTANT DEVELOPMENT RULE:
Do not pretend that video editing is complete if only an interface has been created. Connect each feature to a real processing engine and test it.
